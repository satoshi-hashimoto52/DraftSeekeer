# Security & Privacy

本書は、現行実装で実際に行っていることに限定して記載します。

## 1. データの所在
- 画像・注釈・テンプレートはローカルファイルとして保存
- 主な保存先:
  - `data/datasets/<project>/images`
  - `data/datasets/<project>/annotations`
  - `data/templates`
  - `data/runs`（一部出力）

## 2. 通信境界
- 通信は Frontend（ブラウザ）とローカル FastAPI 間
- 現行コード上、外部クラウドAPI送信は未実装

## 3. 認証・認可
- 認証: なし
- 認可: なし
- CORS: 全許可

このため、公開ネットワークでの直接運用は非推奨です。

## 4. パス取り扱い
- Dataset 名・ファイル名は `Path(...).name` を通してサニタイズする箇所があります。
- ただし、認証なしAPIである点を補うものではありません。

## 5. ログと一時データ
- エラー詳細は Backend コンソールに出力される場合があります。
- ZIP 生成などで `tempfile` を使用します。
- メモリ保持画像（`IN_MEMORY_IMAGES`）はプロセス終了で消えます。

## 6. PII（個人情報）観点
- PII 自動検知・マスキング・匿名化は未実装です。
- 画像に個人情報が含まれる場合、運用側で事前に対策が必要です。

## 7. 推奨運用
1. ローカル端末または閉域ネットワーク限定で運用
2. OSユーザー権限でデータディレクトリのアクセスを制限
3. バックアップ対象を `data/datasets` / `data/templates` 中心に設計
4. コンソールログや一時出力を第三者に共有しない
5. 必要に応じて listen host / CORS を絞る

## 8. 改善候補（未実装）
- API 認証（トークン等）
- API 単位の認可
- 監査ログ
- 出力先の許可リスト化
