# Security & Privacy

本書は現行実装ベースで、実際にコードが行っていることのみを記載します。

## 1. データの所在
- 画像・注釈・テンプレートはローカルファイルとして保存。
- 主な保存先:
  - `data/datasets/<project>/images`
  - `data/datasets/<project>/annotations`
  - `data/templates`
  - `data/runs`（YOLO出力）

## 2. 通信境界
- 通信はブラウザ（Frontend）とローカル FastAPI（Backend）間のみ。
- コード上、外部クラウドAPIへの送信処理は実装されていません。

## 3. 認証・認可
- 認証: なし
- 認可: なし
- CORS: 全許可

このため、公開環境での直接運用は非推奨です。

## 4. ログ/一時データ
- エラー詳細は Backend コンソールに出力される可能性があります。
- 一時ファイル（zip生成等）を `tempfile` で利用。
- メモリ保持画像（`IN_MEMORY_IMAGES`）はプロセス終了で消えます。

## 5. PII（個人情報）観点
- 実装上、PII判定・マスキング・匿名化の自動処理はありません。
- 取り込む画像に個人情報が含まれる場合、運用側で事前対策が必要です。

## 6. 脅威と現状対策
- パス走査対策:
  - export download 系でベースディレクトリチェックあり（`RUNS_DIR` 配下など）
- ただし認証が無いため、プロセス到達可能な利用者には操作可能です。

## 7. 推奨運用
1. ローカル端末/閉域ネットワークでのみ運用
2. OSユーザー権限でデータアクセスを制限
3. バックアップ対象を `data/datasets` / `data/templates` に限定
4. コンソールログを第三者に共有しない
5. 必要に応じて CORS と listen host を限定
